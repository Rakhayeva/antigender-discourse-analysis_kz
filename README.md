 # Автоматизированный дискурс-анализ анти-гендерных движений в Казахстане (2024–2026)

Исследовательский проект по выявлению и систематизации риторических стратегий, используемых казахстанскими публичными акторами для легитимации анти-гендерных позиций. 

Кодирование корпуса текстов выполнено в среде Google Colab с использованием LLM **Anthropic Claude Sonnet 5** через API и валидацией данных через **Pydantic**.

---

## Кратко о методологии

1. **Сбор данных:** Сформирован корпус из 31 публичного высказывания (2024–2026 гг.) по 5 категориям акторов (политики, религиозные лидеры, медиаперсоны, блогеры, артисты/спортсмены).
2. **Кодовая схема:** Разработана смешанная кодовая схема из 37 риторических кодов (индуктивный анализ 6 текстов + дедуктивный анализ 9 теоретических источников: Van Leeuwen, Reyes, Kuhar & Paternotte, Kováts & Põim, Zaremberg, Edenborg, Kambekova, Azhigulova, Cohen).
3. **Автоматизация кодирования:** Разработан строгий системный промпт с логикой Chain-of-Thought (CoT). Ответы моделей валидировались в формат JSON через Pydantic.
4. **Анализ результатов:** Данные агрегированы в Pandas, построена сводная аналитика по частоте кодов и степени уверенности модели (`confidence`), выгружен итоговый отчет.

---

## Главные результаты

* **Доминирующий фрейм:** Ключевым вектором легитимации является **Рамка «навязанных извне» ценностей (Код 1)** — 9 текстов из 31 с высокой уверенностью модели. Анти-гендерная повестка подается не как правовая дискуссия, а как внешняя геополитическая угроза суверенитету.
* **Мобилизационный блок:** Вторым по значимости выступает сочетание **защиты детей/нации (Код 29)** (8 текстов) и **генерации моральной паники (Код 7)** (7 текстов).
* **Символический клей:** Различные группы акторов (депутаты, имамы, блогеры) используют одинаковые риторические приемы, образуя устойчивую дискурсивную коалицию.
